# TV5 - Đánh giá và Báo cáo nghiệm thu (Evaluation Deliverables)

Thư mục này tổng hợp các kết quả thử nghiệm, báo cáo đánh giá mô hình và tài liệu nghiệm thu của Đề tài 18.

## Nội dung chính
- Đối chiếu hiệu năng các phương pháp (Machine Learning vs Deep Learning).
- Báo cáo phân tích ma trận nhầm lẫn (Confusion Matrix), Precision, Recall, F1-Score trên tập dữ liệu tiếng Việt và UCI.
- Kết quả kiểm thử tự động API và giao diện ứng dụng.
- Báo cáo chi tiết và tài liệu định dạng PDF được lưu trữ tại thư mục `docs/`.
